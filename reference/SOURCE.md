# 参考声音来源

## 可选：学术理法派

- `academic.wav` 与 `academic.txt`：用户选定的第一版“学术理法派”试听及其完整逐字稿。
- 来源：Microsoft Edge 在线 TTS，`zh-CN-YunyangNeural`；语速 `-16%`、音高 `-16Hz`、音量 `+0%`，生成日期 2026-09-28。
- 设计方向：宽厚偏沉、温润持重、咬字清楚，以自然讲解的节奏表达概念。
- 由完整 MP3 转为单声道 24 kHz、16 位 PCM WAV，约 22.7 秒；未截取或更改逐字稿。
- 这是通用合成声线的风格调节，不是独占原创音色，也没有使用傅佩荣、曾仕强等人的录音生成该参考。
- 用 API `voice: "academic"` 或客户端 `--voice academic` 选择此参考。CosyVoice 根据它生成新文案，实际声音以本地试听为准，不能保证与参考逐字节或听感完全一致。

## 当前默认：曾仕强公开讲座的人声片段

- Windows 当前本地服务与 Mac 启动脚本默认使用清理后的 `zeng_voice.wav` / `zeng_voice.txt`。API 省略 `voice` 或使用 `voice: "default"` 即选择当前默认；也可用 `voice: "zeng_shiqiang"` 或客户端 `--voice zeng_shiqiang` 明确选择，与学术理法派共用同一模型。
- 页面：[央视网《易经的奥秘（一）何为易经》](https://tv.cctv.com/2009/12/04/VIDE1355510521928255.shtml)
- 页面标注主讲：曾仕强；栏目：百家讲坛。
- 原始节目片段：00:08:00–00:08:09，约 9 秒。
- `reference.wav`：从该片段提取的单声道 24 kHz、16 位 PCM 音频。
- `reference.txt`：通过 CosyVoice 官方演示的语音识别接口取得的参考文字，可能存在识别误差。
- 提取日期：2026-09-28。

### 头尾背景清理（2026-09-28）

用户反馈生成语音头尾出现类似钢琴的声音。代码检查没有发现添加音乐的逻辑；频谱与 Silero VAD 检测显示旧参考的主要语音位于约 2.9–8.14 秒，头部含较长背景区，末尾还有短有声片段。仅凭这些检测不能确认背景乐器种类。

`zeng_voice.wav` 从旧参考保留 2.900–8.140 秒（节目约 00:08:02.900–00:08:08.140），24 kHz、单声道、16 位 PCM，共 5.24 秒；两端各做 5 毫秒渐变，保留句内正常停顿。没有改动音高或语速。逐字稿沿用目标句；本地 Whisper base 对清理片段的转写覆盖目标句，开头个别字有识别误差，因此不作为逐字准确率证明。原始 9 秒录音和旧试听保留，历史素材不标成清理后结果。

复现脚本：`scripts/prepare_zeng_reference.py`。Silero VAD 仅用于离线定位，不是服务运行依赖；没有增加每次合成的音频分离模型。
